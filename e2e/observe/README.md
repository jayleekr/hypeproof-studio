# 실사용 관측 — 강사가 치고, 도구가 본다

```
원장이 친다  →  관측한다  →  이상한 걸 짚는다  →  고친다  →  빌드한다
```

큐시트는 **강사가 채팅으로 몬다.** 여기 있는 것은 그 진행을 자동화하는 도구가
아니라, 진행되는 동안 **무슨 일이 일어났는지 보는** 도구다.

2026-07-26~27 이틀 동안 이 루프로 제품 결함 12건을 잡았다. 자동 스위트가 아니라
**사람이 치는 걸 옆에서 본 것**이 값을 냈다.

## 쓰는 법

```bash
# 릴리스가 나왔을 때 — 빌드 대기부터 관측기 부착까지 한 번에
bash e2e/observe/install.sh v0.1.31

# 이미 앱이 떠 있을 때 — 관측기만 붙이기
HPS_CDP_PORT=9333 node e2e/observe/watch.mjs

# 지금 코치가 뭐라고 하는지 한 번 읽기
node e2e/observe/peek.mjs
```

앱은 반드시 **디버깅 포트와 함께** 떠 있어야 한다:

```bash
open -a "HypeProof Studio" --args --remote-debugging-port=9333
```

| 환경변수 | 기본값 | 뜻 |
|---|---|---|
| `HPS_CDP_PORT` | `9333` | 앱의 원격 디버깅 포트 |
| `HPS_WORKSPACE` | `~/HypeProofClinic` | 산출물을 지켜볼 폴더 |
| `HPS_OBSERVE_OUT` | `runs/session.jsonl` | 기록 파일 |

## 무엇이 보이나

```
💭 생각        내용 + 토큰 수
🔧 툴 호출     이름 + 대상 · 성공/실패 · **실패 사유** · 시각
승인 모달      횟수 + 문구 + 버튼 + 누르기까지 걸린 시간
대화           프롬프트 · 코치 응답
파일           무엇이 언제 생겼나 · 크기
시간 분해      코치가 쓴 시간 vs 사람이 승인을 기다린 시간
```

마지막 줄이 특히 중요하다. `240s (코치 190s + 승인대기 50s)` 처럼 갈라야
"코치가 느린 것"과 "사람이 안 누른 것"을 구분할 수 있다.

## 무엇이 안 보이나

- 코치에게 실제로 나간 시스템 프롬프트 (워커가 조립하므로 밖에서 조회 불가)
- 툴이 돌려준 **성공** 결과의 내용 (실패 사유만 싣는다 — 성공 결과는 길고 대부분 노이즈)

## 왜 이렇게 만들었나 — 계측기 오류 6건

여기 들어간 설계는 전부 **틀려 본 뒤에** 나온 것이다. 고치기 전에 이 목록을 읽어라.

| 짐작한 것 | 실제 | 그래서 |
|---|---|---|
| Playwright 로 채팅에 붙을 수 있다 | 채팅 React 앱은 웹뷰 셸 안의 별도 CDP 타깃(OOPIF)이라 `page.frames()` 에 안 잡힌다 | 웹뷰 타깃에 **직접** 붙고 `Page.createIsolatedWorld` 로 들어간다 |
| 턴이 끝난 뒤 활동 로그를 읽으면 된다 | ~~`toolLog` 는 `streamStart` 마다 `[]` 로 비워진다~~ → **#503 에서 고쳐졌다.** 툴 줄은 이제 대화 타임라인의 일부(`role:"tool"`)라 턴이 넘어가도 남고 workspaceState 에도 저장된다 | 여전히 **도는 동안** 잡는 게 정확하다(모달 대기·상태 전이 시각은 사후에 복원 못 한다). 대신 행이 누적되므로 턴 경계에서 `lineBase` 아래를 걸러야 한다 |
| 로그 행은 추가된다 | `💭` 는 같은 행이 제자리 갱신된다 (`chatTimeline.ts` `timelineTool` — id upsert) | 행 정체성은 **DOM 인덱스**. 라벨을 키로 쓰면 개수가 몇 배로 부푼다 |
| 텍스트가 멈추면 턴이 끝난 것 | 긴 툴 호출 중엔 당연히 멈춘다 | `.hps-btn-stop` 존재 여부가 권위 있는 신호 (`ChatPanel.tsx:612`) |
| 승인 모달은 DOM 에 있다 | macOS 기본은 **네이티브 NSAlert** — DOM 에 없다 | 측정 전에 `window.dialogStyle: "custom"` 을 켜고, 모달은 **워크벤치 페이지**에 있으므로 CDP 연결이 두 개 필요 |
| 붙는 순간부터 세면 된다 | DOM 에 지난 턴의 잔여물이 남아 있다 | 첫 스냅샷은 **기준선만** 잡는다 (`primed`) |

덧붙여, 번들에 코드가 들어갔는지 확인할 때 **한글 문자열로 `grep` 하지 마라.**
esbuild 가 일부 문자를 `\uXXXX` 로 이스케이프해서 거짓 음성이 난다 — 실제로
들어 있는 코드를 "없다"고 하루에 세 번 오판했다. ASCII 식별자로만 검사한다.

## 환경 함정

**세션이 열려 있어야 한다.** 안 열려 있으면 코치가 빈 응답만 낸다 —
`4초 · 툴 0개` 로 끝나는 턴이 그 신호다. 세션은 `/console` 또는 관리 API 로 연다.
`hypeproof-ai.xyz/adult-edu/…` 는 **학생용 안내 페이지**라 세션이 열리지 않는다.

**포트가 오염될 수 있다.** 죽은 인스턴스 때문에 바인드는 되는데 응답하지 않는 상황을
겪었다. 그때는 포트를 바꾸면 바로 붙는다(그래서 기본값이 9222 가 아니다).

**`/json/list` 가 느릴 수 있다.** 45초까지 걸린 적이 있다. 짧은 타임아웃으로
재시도하면 "무응답"으로 오판한다 — 관측기는 그래서 계속 재시도한다.
