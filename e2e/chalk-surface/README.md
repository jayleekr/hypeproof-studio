# chalk-surface — 강사 면이 실제 창에 뜨는가 (#1184)

`run.mjs` 는 **진짜 Studio 앱을 두 번 띄운다.** 다른 것은 아무것도 바꾸지 않고
**심어 넣은 토큰만** 바꾼다.

| 시료 | 기대 |
|---|---|
| 학생 토큰만 | `강사 작업` 뷰 **없음** · 팔레트에 강사 명령 **없음** · 채팅 경로 그대로 |
| issuer 토큰 | 뷰 **있음** · 부제에 cohort · 행동 4개 · 토큰 지우면 **그 자리에서 사라짐** |

양쪽을 다 돌리는 것이 요점이다. 통과 쪽만 재는 검사는 **동작하는 관문과
관문이 아예 없는 것을 구분하지 못한다** (`.claude/rules/verification.md` §2).

```sh
npm ci
HPS_APP_PATH='/path/to/HypeProof Studio Dev.app' node chalk-surface/run.mjs
```

## 알아 둘 것

- **Service 를 띄우지 않는다.** 임시 포트에 `/v1/profile` 만 흉내 내는 서버를
  띄운다. 앱은 프로필이 풀리기 전까지 진입 화면에 멈춰 있고, 강사 면은 그
  뒤에 있기 때문이다. 이 브랜치의 diff 에 worker 변경이 없으므로
  `wrangler dev` 짝을 주장하지 않는다. **다른 세션의 서버를 건드리지 않는다.**
- **심는 토큰은 서명되지 않았다.** 이 관문은 설계상 **검증하지 않는 로컬
  디코드**라서 서명이 있어도 이 관문에 대해 증명하는 것이 없다. 서버가 무엇을
  거부하는지는 #1185 의 몫이다.
- **팔레트 행은 키보드로 고른다.** 화면 밖으로 밀어 둔 창에서는 리스트 행
  클릭이 먹지 않는다(실측).
- 증거는 `e2e/test-results/chalk-surface/` — 스크린샷 3장과 `report.json`.
