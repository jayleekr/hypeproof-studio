# 가상 운영 카드 · L5

실제 계정·주소·인증정보가 없는 탁상 실습이다.

| 구성요소 | 현재 파악한 정보 |
|---|---|
| 도메인 | practice.invalid, 소유자는 원장, 관리 접근은 업체 담당자만 확인 |
| DNS | 업체가 관리하며 변경 이력 위치 미확인 |
| 저장소 | 교육용 저장소, 원장 읽기 가능, 복구 담당은 강사 |
| 배포 | 연습 환경, 정상 버전 A와 오류 버전 B가 있다고 가정 |
| 콘텐츠 | 원장이 최종 확인, 직원이 공지 초안 작성 |
| 백업 | 최근 백업 위치와 복원 가능 여부 미확인 |

카드 A: B 배포 뒤 시간표 링크가 #missing으로 이동한다. A는 #hours로 이동했다.
연습 HTML 사본에서 이를 재현하고 정상 링크로 복구해 확인한다.

카드 B: 업체 담당자가 퇴사했고 도메인 관리 접근을 확인할 수 없다.
실제 계정 복구나 DNS 변경을 실행하지 않는다. 필요한 소유 확인과 담당 인계 항목을 작성한다.

독립 과제: 업체 교체를 앞두고 누가 무엇을 소유하고 어떤 접근과 복구 증거가 필요한지 정리한다.
