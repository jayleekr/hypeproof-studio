# 치과 홈페이지: 판단부터 운영까지, 레벨별 5개 강의

> 자동 생성: program.json을 수정하고 npm run courses:dental로 재생성한다.

사용자가 제공한 Dental Digital Ownership Program 제안서의 L1~L5 정의를 사용한 신규 5강 설계. 원 제안서의 7회 구성과 과거 보아치과 큐시트를 대체하지 않는다. 페르소나는 실제 인물이나 조사 결과가 아닌 설계 가설이다.

## 강사 페르소나

**김서연 (가상 강사)** — 웹 제작·운영 경험이 있고, 비개발자 워크숍을 진행하는 교육 설계자. 치과 임상 지식은 수강생에게 확인한다.

각 원장이 다음 달 반복할 홈페이지 업무 하나를 직접 판단하거나 수행하게 한다.

- 회당 120분, 12명 내외, 2인 1조
- 강의 준비 과정에서 자료와 버전이 흩어지면 안 된다.
- 자동 생성한 강의는 검토 후 사용하며 학습 성공을 자동으로 선언하지 않는다.

진행 방식: 완성 예시 확인 → 작업 의도 작성 → 시연 → 개인 실습 → 다른 조건의 독립 과제 → 검수·인계

## 수강 경로

사전 실기에서 혼자 완료한 가장 높은 수준 바로 다음 강의를 권한다. 낮은 강의부터 모두 수강할 의무는 없다.

- L1: 두 시안 중 하나를 환자의 정보 찾기 관점에서 선택하고 수정 요청을 쓴다.
- L2: 예제의 진료시간을 바꾸고 모바일에서 확인한다.
- L3: 연습 배포의 변경점과 복구 경로를 설명하고 이전 버전으로 되돌린다.
- L4: 새 페이지의 요구사항을 정하고 기존 디자인에 맞춰 제작한다.
- L5: 도메인·계정·배포·복구 책임을 설명하고 모의 장애에서 복구 또는 인계를 결정한다.

각 증거를 0=미제출/작동하지 않음, 1=힌트·도움 후 수행, 2=독립 수행으로 기록한다. 필수 증거 모두 2면 해당 작업의 독립 수행 확인. 평균 점수로 누락을 가리지 않는다. 실제 점수는 빈칸으로 시작한다.

두 시간 수료만으로 운영 전문가나 L5 독립 운영을 인증하지 않는다. L3~L5는 연습 환경 실기와 수업 후 자기 환경 재수행이 필요하다.

## 실행 전 준비

- Studio 설치와 연습 폴더 열기
- 기본 HTML 미리보기 또는 로컬 브라우저로 starter/index.html 열기
- L3 이상은 강사용 연습 저장소와 비운영 배포 환경의 접근·복구를 수업 전에 확인
- 외부 MCP나 플러그인 설치를 수업 시작의 필수 조건으로 두지 않기

이 패키지는 강의 자료와 authoring API 자동화다. Studio 학생 UI·미리보기·배포·복구·MCP가 이 강의 전체를 지원한다는 실행 증거는 아직 없다. 미리보기가 막히면 로컬 HTML, 배포가 막히면 모의 연습으로 전환하고 실기 미완료를 기록한다.

## 기능 요청

- **DENTAL-FR-01 Chalk에서 강의 생성·목록·수정·재열기** (proposed) — 다섯 강의 초안은 API로 저장 가능하지만 강사가 클릭하는 작성 화면은 이 작업에서 검증되지 않음. 대안: 생성된 강의 Markdown과 초안 JSON 사용. 완료 조건: 강사가 한 화면에서 템플릿 선택→수정→저장→재열기를 완료
- **DENTAL-FR-02 HTML 미리보기와 모바일 폭·변경 전후 비교** (needs_student_environment_verification) — 시안 비교와 콘텐츠 수정의 핵심 작업. 대안: 로컬 브라우저에서 두 HTML을 열어 비교. 완료 조건: 390px·1280px 비교와 변경 후 갱신을 학생 환경에서 확인
- **DENTAL-FR-03 연습 배포·정상 버전 표시·복구** (needs_student_environment_verification) — L3 독립 실기와 L5 복구 증거에 필수. 대안: 모의 파일 복원; 배포·복구 실기는 미완료 표시. 완료 조건: 비운영 URL에서 변경과 복구를 실제 확인하고 버전 증거를 남김
- **DENTAL-FR-04 현재 강의·단계가 연결된 기능 요청 창구** (proposed) — 막힌 단계와 필요한 작업을 개발팀에 전달해야 함. 대안: 이 프로그램의 구조화된 요청 목록에 수동 기록. 완료 조건: 강의·단계·원하는 작업·재현·대체 수단·처리 상태를 함께 조회
- **DENTAL-FR-05 추가 렌더러·Plugin·MCP 필요성 사전 검사** (proposed) — 기존 큐시트 README에 외부 MCP 제한 명시; 정적 실습에는 추가 MCP 불필요. 대안: 기본 HTML과 내장 도구; 실제 필요가 생긴 연동은 후속 과제로 분리. 완료 조건: 강사가 도구 요구를 등록하면 지원 여부·권한·학생 환경 점검 결과를 보고 선택

## 상태

자료 생성·스키마 검증과 실제 학습 효과는 별개다. 강사 검토, 학생 기기 리허설, 학습 평가는 아직 미실행이다. 자동 생성은 초안만 준비하며 수업을 활성화하지 않는다.
