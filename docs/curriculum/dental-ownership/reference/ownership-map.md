## 실제 병원 운영 전 확인할 지도

| 구성요소 | 현재 상태 | 확인 행동 | 제안 책임자 |
|---|---|---|---|
| 도메인 소유 | 미확인 | 등록 소유·만료·관리 접근 확인 | 원장 |
| DNS | 미확인 | 관리 주체·현재 설정·변경 이력 위치 확인 | 운영 담당 |
| 저장소·배포 계정 | 미확인 | 소유 조직·권한·접근 복구 확인 | 원장·개발 담당 |
| 운영 백업 | 미확인 | 위치·보관 정책·연습 복원 결과 확인 | 운영 담당 |
| 콘텐츠 | 미확인 | 정보 최종 승인자·갱신 담당 지정 | 원장 |

가상 도메인 practice.invalid는 등록하거나 연결하지 않았다.
비밀번호·토큰을 운영 문서에 넣지 않는다. 소유·접근 여부와 담당만 기록한다.
