# L4 · 채용 페이지 요구사항과 인계

대상은 가상의 지원자. 목표는 역할·업무·조건 확인 방법·지원 절차·문의 안내를 이해하는 것이다.

| 요구사항 | 구현 위치 | 검수 |
|---|---|---|
| 모집 역할 표시 | #role | 역할 명칭과 제목 일치 |
| 업무 안내 | #work | 교육용 업무임을 표시 |
| 근무 조건 확인 방법 | #conditions | 확인되지 않은 조건을 확정하지 않음 |
| 지원 절차 | #process | 순서를 읽을 수 있음 |
| 문의 안내 | #contact | 실제 개인정보 수집 기능 없음 |

기존 본문의 색, 글자, 간격과 상단 메뉴를 재사용한다. 새 프레임워크·DB·인증·MCP는 필요하지 않다.
홈에서 채용 페이지로, 채용 페이지에서 홈과 시간표로 이동할 수 있어야 한다.
390px·1280px에서 확인한다. 가상 모집 역할은 진료 지원 담당으로 바꾼 최종 예제다.

가상 원장이 공고 담당이며 역할·조건·절차가 바뀌면 재검수한다.
파일 생성과 연습 HTTP 게시, 운영 사이트 공개는 구분해 기록한다.
