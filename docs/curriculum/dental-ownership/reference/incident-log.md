# L5 · 모의 장애 대응

## A: 배포 뒤 시간표 이동 오류

증상: 상단 링크가 #missing을 가리킨다. 정상은 #hours.
영향: 방문자가 메뉴에서 시간표로 이동할 수 없다.
조치: 연습 서버에서 오류 버전을 확인한 뒤 직전 정상 버전으로 전환한다.
증거: 실행 보고서의 오류 감지·복구 후 링크 확인·응답 해시. 실제 수행 성공 여부는 그 보고서가 정한다.

## B: 업체 담당자 퇴사, 도메인 접근 불가

탁상 시나리오이며 실제 장애가 아니다.
초기 확인: 소유자, 등록·관리 계정 주체, 최근 정상 서비스 상태, 업체 인계 가능 여부.
조치: 계정 소유자에게 접근 복구와 담당 변경을 요청할 자료를 준비한다. DNS 값을 추측해서 변경하지 않는다.
인계: 도메인 식별자, 소유 확인 상태, 마지막 정상 확인, 요청 목적, 연락 가능한 담당. 인증정보는 문서에 넣지 않는다.
완료 기준: 실제 소유자가 관리 접근과 변경 권한을 확인한 후 별도 연습 계획 수립. 현재 미실행.

## 백업 복구 연습

원본과 다른 임시 디렉터리에 백업을 복원하고 해시를 비교한다.
의도적으로 오염시킨 백업은 검증에서 거부돼야 한다. 복원한 HTML은 HTTP로 열어 다시 확인한다.
이는 실제 클라우드 전체 재해 복구나 도메인 복구를 대신하지 않는다.
