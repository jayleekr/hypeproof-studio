# L1 · 강사용 판단 과제 예시 답안

가상 대상: 모바일로 처음 방문할 치과의 진료시간과 위치를 확인하는 성인.
우선 질문: 언제 방문할 수 있는가, 어디에 있는가, 방문 전에 무엇을 확인해야 하는가.
우선 행동: 진료시간으로 이동해 요일별 시간을 확인한다.

| 현재 상태 | 수정 요청 | 확인 기준 |
|---|---|---|
| 시안 B는 body가 1100px 고정 폭 | 화면 폭에 맞는 본문 폭과 내부 여백 적용 | 390px 화면에서 문서 폭이 화면 폭을 넘지 않음 |
| 시안 B는 본문 11px | 기본 본문을 예제 A의 18px 수준으로 조정 | 계산된 본문 글자 크기와 실제 가독성을 확인 |
| 시안 B는 950px 높이 소개 영역 뒤에 시간표, 바로 가기 없음 | 상단에 진료시간 링크를 제공 | 첫 화면에서 링크가 보이고 누르면 시간표로 이동 |

선택: A를 작업 시작점으로 삼는다. 정보 찾기와 작은 화면 대응이 작업 목적에 맞는다.
이는 수강생의 취향 점수가 아니라 강사용 비교 예시다. 실제 사람의 판단은 별도로 기록한다.

인계: 원장은 정보의 정확성과 우선순위를 결정한다. 구현 담당은 레이아웃과 링크를 바꾼다.
완료 판단은 화면과 링크를 다시 확인한 후 한다.
