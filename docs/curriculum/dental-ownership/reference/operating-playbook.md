# L5 · 통합 운영 수칙 (강사용 예제)

이 문서는 실제 원장의 운영 자격 인증이 아니다. 연습에서 실행한 범위와 실제 병원 확인 항목을 구분한다.

## 변경·반영·복구

1. 요청: 대상 페이지, 현재 상태, 원하는 상태, 확인 방법을 적는다.
2. 원본 보관: 정상 버전과 백업 위치·해시를 기록한다.
3. 수정: 요청한 콘텐츠만 바꾼다. 외부 연동은 별도 요구사항으로 분리한다.
4. 검수: 내용, 390px·1280px 화면, 시간표와 페이지 이동을 확인한다.
5. 반영: 대상이 연습인지 운영인지 확인하고 버전을 지정한다.
6. 재확인: 실제 열린 URL의 내용과 버전을 확인한다. 저장만 됐으면 공개 완료로 쓰지 않는다.
7. 중단: 링크 오류, 내용 불일치, 백업 불확실, 계정 권한 불명확이면 다음 반영을 멈춘다.
8. 복구: 확인된 정상 버전으로 돌아가 실제 URL에서 다시 확인한다. 복구 실패면 증거와 함께 담당자에게 인계한다.

## 분담

| 작업 | 제안 담당 | 인계 조건 |
|---|---|---|
| 진료시간·공지 수정 | 원장/지정 직원 + Studio 보조 | 사실 확인 불가, 구조 변경 필요 |
| 새 정적 페이지 | 교육 이수 담당 + 개발 지원 | 인증·결제·정보 수집 연동 필요 |
| 연습 배포·복구 | 지정 운영 담당 | 접근 불가, 정상 버전 불명확 |
| DNS·계정 복구 | 계정 소유자·전문 운영자 | 권한 확인 전 변경하지 않음 |
| 내용 최종 승인 | 원장 | 의료적 정확성 자동 승인 금지 |

## 반복 관리

- 매 변경: 변경·검수·실제 반영 버전·복구 경로를 기록한다.
- 월별 운영 점검 제안: 주요 페이지·링크, 담당자 변경, 백업 복원 가능성, 도메인 만료 확인.
- 담당자 변경 시: 계정 소유·접근·백업·미해결 요청을 인계한다.
- 유지보수 계약 전: 맡길 작업, 응답 목표, 지원 시간, 비용과 예외를 실제 공급자와 합의한다. 여기에는 약정이나 가격을 확정하지 않는다.

## 이번 연습의 종료 조건

브라우저/HTTP 검사는 자동 보고서로 확인한다. 도메인·클라우드 호스팅·실제 계정·운영 백업은 미확인으로 유지한다.
