# 시안 B 결함 평가 — 화면 위치 연결

> 작성일: 2026-09-06  
> 실측 출처: 관측자가 Studio 내장 브라우저 CDP로 390px 뷰포트를 직접 적용해 측정한 값 (독립 수행 아님, 관측자 도움)  
> 코치 직접 확인: browser_screenshot (브라우저 기본 너비, 390px 고정 불가)

---

## 결함 1 — 가로 스크롤 (documentWidth 1130px vs viewport 390px)

- **관측자 실측**: 390px 뷰포트에서 `documentWidth 1130px` — 화면 너비의 약 2.9배
- **원인**: `body { width: 1100px; }` 고정값이 뷰포트를 무시하고 페이지 전체를 가로로 넓힘
- **화면 위치 영향**: 모든 칸(공지·진료시간·찾아오는 방법)이 오른쪽으로 잘려서 보이고, 환자가 좌우로 밀어야 내용을 확인할 수 있음
- **코치 스크린샷 확인**: 브라우저 기본 너비에서는 가로 스크롤이 보이지 않았으나, 맨 위 "가상 교육용 비교 시안 B" 문구와 본문이 왼쪽 좁은 영역에만 표시됨 → CSS 구조상 390px 환경에서 가로 잘림이 발생함을 HTML 분석으로 재확인

---

## 결함 2 — 작은 글자 (본문 11px)

- **관측자 실측**: 390px 뷰포트에서 본문 렌더링 크기 **11px**
- **원인**: `body { font: 11px/1.5 system-ui; }` — CSS 선언 자체가 본문 글자를 11px로 직접 지정함. scale-down이 원인이 아니라 폰트 크기 선언이 원인 (검수 후 수정됨)
- **화면 위치 영향**: 메뉴 링크·병원명·진료시간 표의 모든 글자가 작아져 가독성 저하. 시안 A 본문(18px, 관측자 실측)과 비교해 약 60% 수준
- **코치 스크린샷 확인**: 시안 B 스크린샷에서 "온유 연습치과" 제목·"진료시간 안내는 아래에서 확인하세요" 문구가 시안 A 동일 요소보다 눈에 띄게 작게 표시됨 (시각적으로 직접 확인)

---

## 결함 3 — 첫 화면 아래에 위치한 진료시간 (#hours top 1081.2px)

- **관측자 실측**: 390px 뷰포트에서 `#hours` 시작 위치 **top 1081.2px** — 첫 화면(390×844px 기준)에서 약 1.3배 아래
- **원인**: 병원명 아래 `hero` 영역에 CSS `height:950px` 고정이 걸려 빈 공간을 강제로 확보하고, 그 아래에 진료시간 칸이 위치함
- **화면 위치 영향**: 환자가 진료시간을 보려면 거대한 빈 녹색 영역을 모두 지나야 함. top 1081.2px는 첫 화면(844px) 아래이므로 반드시 스크롤이 필요하며, 정확한 스크롤 횟수는 측정하지 않아 기재하지 않음
- **코치 스크린샷 확인**: 시안 B 스크린샷에서 화면 전체가 병원명·한 줄 안내·녹색 빈 영역으로 채워져 있었으며, 진료시간 텍스트는 스크린샷 안에 나타나지 않았음 (직접 확인)
- **시안 A 비교**: 관측자 실측 `#hours top 497.1px` — 같은 390px 뷰포트에서 시안 B의 절반 이하 위치에 진료시간이 위치
