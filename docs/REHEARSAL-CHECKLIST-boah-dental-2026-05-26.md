## Tier 3 인간 평가 시트

### T3.1 — 5블록 페이싱 자연스러움 (60분 in-flow)
| 블록 | 목표 시간 | 실제 | 자연스러웠나? |

| 도입 | 5분 | __분 | ☐ 자연 ☐ 어색 |

블록 전환 시 강사 개입 없이 코치가 다음 블록으로 유도하는지.

### T3.2 — 원장님 판정 → 한 줄 규칙 환원 흐름
실제로 V1 한 개를 만들어 코치에게 *모의 원장님* 판정을 받아보세요.
- [ ] 코치가 PASS / 더 확인 / 위험 중 하나의 판정을 명시
- [ ] 판정 직후 "방금 깨진 이유가 뭐였죠?" 패턴으로 규칙 환원 유도
- [ ] 참가자가 V2로 수정하는 흐름이 자연스럽게 이어짐

### T3.3 — 검색스킬 패킷 저장 자연 유도
세션 후반에:
- [ ] 코치가 "다음에도 쓸 규칙 형태로 저장하자" 흐름을 던지는지
- [ ] 패킷 6요소(검색 목적·질문 템플릿·신뢰 출처·걸러낼 출처·판정 로그·재사용 규칙) 중 ≥4개 언급

### T3.4 — 직군 다양성 커버
한 명이 위생사 시나리오, 한 명이 코디 시나리오, 한 명이 사모님 시나리오로 진행:
- [ ] 위생사: 환자 안내 근거 찾기 자연스럽게 진행됨
- [ ] 코디: 표현 톤 정리 자연스럽게 진행됨
- [ ] 사모님: 제품/장비 비교 자연스럽게 진행됨
- [ ] 직군 캡션 칩이 실제로 도움됨 (그냥 장식이 아님)

### T3.5 — 강사 무개입 자체 동작
강사가 한마디도 안 했을 때:
- [ ] 코치가 막힌 참가자를 자체적으로 unstick 시켜줌
- [ ] AI 결론을 그대로 받으려 할 때 "원장님 질문으로 변환" 자동 발동
- [ ] 광고/판매성 출처 가져오면 자체적으로 "보류" 권고
