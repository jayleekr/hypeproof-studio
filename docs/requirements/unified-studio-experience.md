# 체험·수업 통합 요구사항

2026-09-10 · [Intent/Epic #915](https://github.com/jayleekr/hypeproof-studio/issues/915)
상태: 구현 목표 발행안. 제품 책임 Jay (`jayleekr`). 모든 US 행은 신규 전체 수용 기준이며
현재 구현/배포 PASS를 의미하지 않는다. 기존 동작은 [조사 표](../design/unified-studio-experience.md#문제와-확인한-기반)로 구분한다.

상위 [INT-US-01~04](../design/unified-studio-experience.md#product-intent)와 기존 NAT/AE/AB,
REQ-I 업데이트 계약을 확장한다. P0는 통합 사용자 경로 출시 필수다. P1은 코드 없는 공개 발급
정책 확정 후의 추가 진입이며 P0의 기존 참여 코드 경로를 없애지 않는다.

## 범위 해석

- US-01/02는 App과 Service의 전달 경로 통합이다. 서로 다른 수업의 데이터·강사 권한·Module pin까지 합치는 요구가 아니다.
- US-04의 레거시 native-trial 참여 코드는 호환 경로다. 신규 개인 권한은 AB-02를 따라 기존 account/access에 연결하며 임시 가짜 수업 등록을 새 개인 가입 모델로 채택하지 않는다.
- US-14의 자동 gate 구현은 [배포 절차](../dev/unified-release-and-migration.md)에 연결한다. #912의 수동 체크리스트나 판정기 단위 성공만으로 최종 인수를 충족하지 않는다.
- 신규 로그인 공급자·가격/결제·재체험 횟수·기간/무료량은 이 문서로 확정하지 않는다. 운영 조건이 정해지기 전 합성 정책으로 구현·검증할 수 있지만 공개 발급은 활성화하지 않는다.

각 US 행의 원본은 이 표다. 구현 이슈·PR은 행 ID와 [US 테스트](../testing/unified-studio-experience.md)를
참조하고 구현, 실기, 공개 배포를 별도 상태로 갱신한다. 기존 NAT/AE/AB 표를 복사해 독립 정책으로 만들지 않는다.
