# 개인 체험 화면 조작 요구사항

추적 이슈: [#758](https://github.com/jayleekr/hypeproof-studio/issues/758). 상위 요구사항은 [NAT-01~12](studio-native-trial.md), 자산 정의는 [7 AI Native Assets](../seven-assets.md)를 따른다. 이 문서는 버튼을 눌렀을 때 사용자가 확인해야 할 결과를 정의한다. 실행 여부는 [테스트 문서](../testing/studio-native-trial-ux.md)와 실행 보고서에 기록한다.

기준은 `studio-native-trial` 프로필과 실제 React/호스트 소스다. 최초 인벤토리는 main `fe6f7b5`에서 확인했다. 체험은 성인용 고정 이름 ‘코치’, 시작 예시 3개, 이미지 첨부, 응답 재시도, 작업 관찰을 제공한다. 아동 캐릭터·갤러리·네이밍·입력 다듬기·후속 예시는 이 프로필에서 노출되지 않는다. 학습 자료의 버튼과 앱 버튼을 혼동하지 않는다.

## 공통 기준

- 클릭과 키보드로 같은 동작을 할 수 있어야 한다. 포커스와 조작 이름을 식별할 수 있고, 처리 중·실패·다음 행동을 화면에서 알 수 있어야 한다.
- 클릭 이벤트 전송만으로 성공 처리하지 않는다. 폴더·코치·미리보기 열기, 삭제, 평가, 업데이트는 해당 호스트나 서버의 실제 결과까지 별도로 확인한다.
- 인증·도구·비용 권한은 기존 Service 정책을 따른다. 시작 버튼은 누르는 시점에 유효성을 재확인한다. UI의 연결 카드나 토큰 존재만으로 실행 가능하다고 판단하지 않는다.
- 되돌릴 수 없는 대화 삭제는 확인 또는 실제 복구 수단을 제공한다. 취소는 대화·파일·예약 초안을 잃게 하지 않는다. 연결 해제는 자격증명을 지우며 작업 파일을 삭제하지 않는다.
- 접근성·좁은 화면·오류 상태도 요구사항이다. 점수나 사람의 학습 효과는 버튼 테스트로 입증하지 않는다.

## 공통 UI 용어

체험판과 일반판의 인증·오류·시작 안내는 나이에 관계없이 같은 용어를 사용한다. 자격 증명은 사용자에게 ‘참여 코드’, 발급·재발급 연락 대상은 ‘코드 발급 담당자’, 장애 문의는 ‘운영 담당자’로 표시한다. 강의 진행자 역할만 ‘강사’로 부른다. 공통 UI에 ‘선생님’이나 ‘새 토큰’을 사용하지 않는다. TUX-COPY-01은 만료·누락·권한·연결 실패의 공통 메시지와 시작 화면에 적용한다.

셸 노출 조건 정정(2026-09-08): `resolveActionApproval`만 보면 일반 셸 확인이 존재하지만, 체험의 `evaluateSdkToolUse`는 비파괴 Bash를 그 전에 자동 허용한다. 정상 체험에서 일반 ‘항상 허용’ 창을 기다리는 것은 잘못된 판정이다. 이 정정은 제품 권한이나 승인 정책을 바꾸지 않는다.
