# 독립 강의 개설 요구사항

상태: 구현 계약 · 2026-09-13 · [#1006](https://github.com/jayleekr/hypeproof-studio/issues/1006).
상위: [Product Intent](../PRODUCT-INTENT.md)의 useful work first와 권한 경계.
기존 [Chalk](chalk-authoring.md)의 CH-01/04, VER-01, RUN-03과
[AE](learning-agent-experience.md)의 AE-09/11/26을 확장한다.
새 강의 작성으로 기관·모델·도구·예산 권한을 얻지 않는다.

## 요구사항

| ID | 관측 가능한 계약 |
|---|---|
| IC-01 | 기존 고객 프로필 선택 없이 대상·목적·단계·검수 기준을 가진 새 강의를 저장·재열기·확정한다. 내부 식별자는 자동 생성하며 기존 강의 ID를 덮어쓰지 않는다. |
| IC-02 | 관리자가 허용한 개설 범위와 실행 템플릿만 강사에게 제공한다. 직접 API 요청의 타 기관·미허용 템플릿·모델·도구 확대를 거부한다. 템플릿 미확정은 초안 저장을 막지 않고 개설 불가 사유로 표시한다. |
| IC-03 | 작성/확정과 실제 수업 개설을 분리한다. 개설 때 일정·명단·확정 버전·실행 설정 revision을 명시적으로 선택한다. 중복 클릭·응답 유실 재시도는 같은 수업을 돌려주고 다른 요청의 수업을 덮어쓰지 않는다. |
| IC-04 | 학생 자격으로 리허설하고 해당 확정 버전·정책·템플릿·App/Service에 근거를 귀속한다. 강사 전용 자격을 리허설에 전달하지 않고 관련 수정 뒤 이전 합격을 재사용하지 않는다. |
| IC-05 | 개설한 수업의 참여 코드로 Studio에 진입해 자기 목표에 맞는 첫 응답과 실제 파일 작업을 수행한다. 다른 기관 이름·환영 문구·자료가 새 강의에 남지 않는다. 문구 교체만으로 새 실행 연결을 성공 처리하지 않는다. |
| IC-06 | 기존 수업·기발급 코드의 버전·권한·작업은 유지한다. 새 수업 종료·AI 자격 만료 후 자기 파일은 재열기 가능하며 타 수업 자료와 실행 자격은 내보내지 않는다. |
| IC-07 | 생성 중/초안/개설 가능/리허설 미실행/권한 거부/버전 충돌/개설됨을 구별한다. 오류·409에서 입력을 보존하고 다음 조치를 안내한다. 키보드·390px·200% 확대에서도 개설/취소/오류 확인이 가능하다. |

## 설계

Service가 기존 issuer scope·authoring revision·roster/token 서명을 소유한다.
Chalk는 허용된 템플릿 선택과 초안·확정·개설 화면을 제공한다. compiled profile을
고객별로 복제하는 대신 불변 실행 템플릿과 강의 내용을 구별한다. 모델·도구 집행은
현재 lesson binding의 교집합을 재사용한다. 새로운 인증/예산 저장소를 만들지 않는다.
템플릿 ID, 강의 revision, 개설 operation ID, 생성 session ID를 연결하고 idempotency
충돌에서는 기존 결과를 덮어쓰지 않는다. 학생별 프로젝트 사본은 자격과 별도로 유지한다.

첫 PR은 IC-01/02/03의 초안과 개설 계약을 기존 코드에서 구현하고 합성 두 기관으로
검증한다. IC-04는 학생 리허설 packet, IC-05/06은 실제 App 통합 인수로 이어간다.
기존 #1005의 프로필 선택·ID 자동 생성 성공을 IC 전체 완료로 취급하지 않는다.
