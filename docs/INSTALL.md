# HypeProof Studio 설치 가이드

SK바이오팜 워크숍 가족 여러분 환영합니다. 5분 안에 설치 끝납니다.

---

## 🍎 Mac

1. **Spotlight** (⌘+Space) → "Terminal" 입력 → Enter
2. 아래 한 줄을 복사해서 붙여넣고 Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/jayleekr/hypeproof-studio-releases/main/install-mac.sh | bash
```

3. 다 끝나면 자동으로 HypeProof Studio가 열립니다.

> **첫 실행 경고**가 뜨면:
> 시스템 설정 → 개인정보 보호 및 보안 → "확인 없이 열기"를 누르세요. (서명 인증서 작업이 아직 진행 중입니다.)

---

## 🪟 Windows

1. **시작 버튼** → "PowerShell" 입력 → 우클릭 → "관리자 권한으로 실행"
2. 아래 한 줄을 복사해서 붙여넣고 Enter:

```powershell
irm https://raw.githubusercontent.com/jayleekr/hypeproof-studio/main/scripts/install-win.ps1 | iex
```

3. SmartScreen 경고가 뜨면 → "추가 정보" → "실행" 클릭

---

## 워크숍 토큰 등록

설치 후 처음 열면 좌측에 💬 아이콘이 보입니다.

1. 💬 아이콘 클릭
2. 화면 위쪽 **"Set token"** 버튼 클릭
3. 운영진이 나눠드린 토큰 문자열 붙여넣기 → Enter

이제 채팅창에 무엇이든 입력해보세요 — 예:
> "삼각형을 그리는 게임을 만들어줘"
