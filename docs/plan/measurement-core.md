## 결정

- Jay부터 실제 제품 작업에 사용한다.
- Studio 기능을 공통 코어로 추출하고 Studio·Claude Code·Codex에 연결한다.
- 새 제품은 **6개 모델을 기본으로 시작한다**. 기존 7개는 legacy 기록으로 보존한다.
- 처음부터 로컬에서 검토·제출·다음 작업 피드백까지 이어지게 만든다.
- 팀 강제 적용·원격 연구 수집은 후속으로 붙인다.

## 첫 수직 경로

첫 코어 추출 후 가장 빨리 확인할 경로는 `실제 host event → 같은 코어 → 근거를 여는 카드 → Jay 정정 → local receipt`다. Claude Code를 먼저 검증하고 Codex로 이식성을 확인하되, 설치 환경이 지원하지 않으면 그 사실과 순서 변경 이유를 기록한다. 외부 어댑터의 편의 때문에 Studio 재연결을 삭제하지 않는다.

## 기존 작업과 관계

[#852](https://github.com/jayleekr/hypeproof-studio/issues/852)는 양쪽 validator·legacy 호환·모델 버전 계약을 다룬다. 여섯 모델 채택에 대한 Jay의 이번 결정을 반영하되 원자료 보존·행위자 구분·새 해석의 버전화를 유지한다. #852를 중복 완료 처리하거나 새 문서로 구현을 대체하지 않는다.

기존 Studio/Chalk 작업과 수업 정책을 보존한다. 전체 앱 빌드·production 배포 없이 시작하며, 필요한 설치·extension 연결 검증을 먼저 수행한다. 제품 출시 단계에서 실제 앱 배포가 필요하면 기존 release 절차를 따른다.

## 완료 보고의 기준

- 기준 문서 완료: #1021의 문서·traceability 검증과 PR.
- 구현 완료: 해당 코드 경로와 양성·음성 시험이 실제 실행됨.
- 첫 사용 가능: 설치된 지원 host에서 local 검토·제출 경로가 실제 작동함.
- Jay dogfood 완료: 세 host 공통 코어 연결과 MC-T22의 Jay 관찰·후속 판단이 있음.
- 연구 진전: 모델 변경 근거와 반례 검토가 있음. 데이터량이나 CI 통과로 대체하지 않음.

현재 완료를 주장하는 범위는 기준 문서와 단위 1의 합성/소스 통합 하위 범위뿐이다. 외부 adapter와 로컬 검토·제출 제품 경로는 아직 설치·실행하지 않았다.
