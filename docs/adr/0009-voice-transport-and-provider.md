# ADR-0009 — 음성 전송·공급자 (VO-02)

- **상태**: 제안. **결정은 내려지지 않았다.**
- **날짜**: 2026-09-11
- **관련**: [#896](https://github.com/jayleekr/hypeproof-studio/issues/896) Intent · [#897](https://github.com/jayleekr/hypeproof-studio/issues/897) V0 · [#898](https://github.com/jayleekr/hypeproof-studio/issues/898) V1 · [#901](https://github.com/jayleekr/hypeproof-studio/issues/901) V4 · REQ-R1 · REQ-R5 · [vscodium#2](https://github.com/jayleekr/vscodium/pull/2)

이 문서는 **결정하지 않는다.** 선택지를 이 제품의 제약 위에 놓고, 각 선택지가 무엇을 요구하는지 적는다. 고르는 것은 사람의 일이다 — 특히 미성년 약관과 보안 범위가 걸려 있다.

---

## 0. 순서를 먼저 바로잡는다 — 전송보다 **캡처**가 앞이다

조사에서 공급자 네 계열을 모두 훑은 뒤, 반증 단계가 공통된 구멍을 짚었다: **네 보고서 전부 "오디오가 공급자에 닿을 수 있나" 를 먼저 물었고, 그 앞의 질문을 묻지 않았다 — 애초에 오디오를 잡을 수 있나.**

지금 잡을 수 없다. 실측으로 아는 것은 둘이다:

- webview iframe 의 Permissions-Policy allow 목록에 `microphone` 이 **0건**
- Electron 메인 프로세스의 **webview** 권한 집합에 `media` 가 **없음** (설치본 `out/main.js`)

**어느 쪽이 거부하는지는 모른다.** 내부 iframe 이 same-origin 이고(`allow-same-origin` + 같은 출처 `fake.html`) `microphone` 의 기본 allowlist 가 `self` 이므로, allow 속성의 누락이 비활성화를 뜻하는지 MDN 이 명확히 적지 않는다(iframe·Permissions-Policy 두 페이지, 2026-09-11). 패치된 빌드(run `34616771276`)가 가른다.

**그래서 이 ADR 의 선택지는 "어느 공급자" 가 아니라 먼저 "어디서 캡처하나" 로 갈린다.**

같은 실측에서 나온, 선택지를 넓히는 두 사실:

| 사실 | 의미 |
|---|---|
| `media` 는 **워크벤치 문서**(`vscode-file://vscode-app`)에 **이미 허용**돼 있다 | 막힌 것은 webview 프레임뿐이다 |
| webview 는 오늘 **네트워크 I/O 를 전혀 하지 않는다** — 모든 외부 호출이 확장 호스트(Node)에 있고 거기엔 CSP 가 없다 | 전송 소켓을 확장 호스트가 열면 **CSP 변경이 필요 없다** |

## 1. 이 제품이 전송에 강제하는 것

| 제약 | 근거 | 강도 |
|---|---|---|
| 채팅 패널 CSP 는 지시자 **여섯 개**뿐이고 `connect-src` 가 webview 출처만 허용한다. `media-src`·`worker-src`·`blob:` 없음 | `cspBuilder.ts:23-30`; 전체 문자열 일치 단언 `pre-voice-text-flow.smoke.mjs` | **하드.** 웹뷰에서 공급자로 직접 연결은 구조적으로 불가 |

| 오디오 거절이 **계량되는 좌석 전용**이다 | `messages.ts` 의 `if(executionAccess)`; REQ-R3 ⑥ | 하드. 계량 없는 좌석엔 가드가 없다 |

| `speaking` 중 캡처를 열어 두는 설계(끼어들기 조건) → 에코 구간 존재 | REQ-R5 ④ | 소프트. 에코 억제는 미해결 |

## 2. 결정적 필터 — 미성년 약관

아동 코호트 둘(`sk-biopharm-kids-2026-grade-3-4-s1`, `...grade-5-6-s1`)이 있다. 이 필터가 선택지를 가장 빠르게 줄인다.

| 계열 | 미성년 관련 | 출처 확인 |
|---|---|---|
| **Anthropic** | 유일한 오디오 경로가 **claude.ai 계정**을 요구하고, 소비자 약관이 "at least 18 years old" 를 요구한다 | 2026-09-11 확인 |
| **Google Gemini** | 개발자 API 약관: **"You must be 18 years of age or older to use the APIs"** | 2026-09-11 확인 |
| OpenAI · 전용 벤더 | 위와 같은 전면 금지 문구는 확인되지 않았다 — **다만 제가 전수 조사하지 않았다** | 부분 |
| **온디바이스** | **오디오가 제출되지 않으므로 보존·학습 조항이 존재하지 않는다** | 구조적 |

**Anthropic 에는 오디오 API 가 아예 없다.** 오디오 콘텐츠 블록 요청(anthropic-sdk-python #1198)은 **not-planned 로 닫혔다**. 그래서 "코치가 Anthropic 이니 음성도 Anthropic" 은 선택지가 아니다.

대신 반증 단계가 **Anthropic 자신의 1차 문서**를 찾았다 — Claude Cookbook 의 "Low latency voice assistant with ElevenLabs". 즉 **Anthropic 이 문서화한 패턴 자체가 "제3자 STT/TTS + 추론은 Claude"** 이고, 그게 이 레포의 모양과 맞는다(코치는 그대로, 말하기·듣기만 따로).

## 3. 선택지

### A. 온디바이스 (로컬 STT/TTS)

**검증된 것:**
- macOS 에 한국어 음성이 **이미 있다** — 이 기계에서 `say -v '?'` 로 `ko_KR` 음성 **9종** 확인(Yuna 외).
- 설치본은 **Electron 39.8.7 / Chromium 142** — Chromium 139 에서 들어간 on-device Web Speech 개선 이후다.
- 한국어 ASR 에 문서화된 숫자가 있다: NVIDIA `nemotron-3.5-asr-streaming-0.6b`, **ko-KR CER 7.12% @ 1.12s chunk**.
- `stopSpeaking(at:)` 로 취소 가능하고, 파이프라인을 우리가 소유하므로 **들은 범위를 부분적으로 보고할 수 있다** — REQ-R5 ⑥ 의 `HeardExtent` 가 바라는 바로 그것.
- **기존 텍스트 경로를 그대로 쓴다.** STT 가 문자열을 만들면 `/v1/chat/completions` 에 변화 없이 들어가고 TTS 는 응답 문자열을 먹는다. **새 프로토콜·새 meter 가 필요 없다.**

**비용:** 공급자 한계비용 0. 대신 **빌드·배포 파이프라인**으로 문제가 옮겨간다 — 모델 바이트를 어떻게 넣고 갱신하나. 반증자가 정확히 이 점을 짚었다. 그게 이 선택지의 진짜 값이다.

**미검증:** 실제 지연·정확도를 이 제품의 기기에서 재지 않았다. CER 7.12% 는 벤더 수치다.

### B. OpenAI (realtime / 또는 평범한 HTTP)

**검증된 것:**
- 서버-투-서버 WebSocket 이 문서화돼 있고 **API 키가 백엔드에 남는다** — 클라이언트가 자격증명을 들지 않는다.
- **WebSocket 이 아예 필요 없는 경로도 있다**: `/v1/chat/completions` 에 `modalities:["text","audio"]` + `input_audio` 블록, 그리고 별도 STT(`/v1/audio/transcriptions`)·TTS(`/v1/audio/speech`) 엔드포인트. 전부 평범한 HTTP POST.
- 한국어 인식·합성 지원. **다만 WER 수치 공개 없음**, TTS 는 "영어 최적화" 명시.

**문제 둘:**
1. **가격 단위가 우리 엔진과 안 맞는다.** realtime 은 토큰당, GPT-Live 는 **분당**(`$0.05/min`), STT/TTS 는 분당·글자당이 섞여 있다. 우리 엔진은 이름 붙은 meter 로만 가격을 매긴다 → **새 차원이 필요하다(#901 V4).**
2. **"Cloudflare Worker 가 아웃바운드 WebSocket 을 열 수 있다" 는 확인되지 않았다.** 조사가 그렇게 적었고 반증 단계가 **인용한 문서에 그런 문장이 없다**고 뒤집었다. 평범한 HTTP 경로를 택하면 이 문제가 사라진다 — 그게 이 선택지 안에서 HTTP 를 선호할 이유다.

### C. 전용 음성 벤더

**검증된 것:**
- 다섯 벤더 모두 서버-투-서버 경로가 있고, **클라이언트에 자격증명을 요구하는 곳은 없다.**
- **Deepgram 은 한국어 TTS 가 없다** (Aura/Aura-2 언어 목록에 부재). STT 는 `ko`·`ko-KR` 지원.
- ElevenLabs 한국어 WER 은 자체 공개 **"Good" 대역(>10%~≤20%)** — 시험 세트 미명시.
- **Azure Voice Live 는 koreacentral 에서 ko-KR 이 안 된다**(반증 단계가 지역 문서로 확인). 가격 주장도 실행 가능하지 않다고 뒤집혔다.
- 한국어 전문 벤더(ReturnZero 등)가 존재하고 자체 수치를 낸다.

**문제:** 가격 단위가 분당·시간당·1,000자당으로 갈리고 **전부 우리 meter 에 없다.**

### D. Google Gemini Live

서버-투-서버 WebSocket 이 문서화돼 있고 barge-in 이 이름으로 지원된다. **그러나 개발자 API 약관이 18세 이상을 요구한다** — 아동 코호트에 쓸 수 없다.

그리고 **이 계열 조사는 신뢰도가 가장 낮다**: 반증 단계가 **존재하지 않는 인용문**을 하나 찾아냈고(한국어 로케일 관련), 한계 서술이 과장됐고, ephemeral token 엔드포인트가 잘못 귀속됐다. 이 계열을 진지하게 보려면 **다시 조사해야 한다.**

## 4. 이 제약들이 시사하는 것

세 가지가 한 방향을 가리킨다. **결정은 아니지만 기록한다.**

1. **미성년 필터가 Anthropic 과 Gemini 를 지운다.** 아동 코호트에 대해서는 선택지가 온디바이스·OpenAI·전용 벤더로 줄어든다.
2. **원가 엔진이 유료 옵션 전부에 새 차원을 요구한다**(#901 V4 선행 조건과 일치). 온디바이스만 이 비용이 0 이다.
3. **온디바이스는 CSP 질문 자체를 없앤다** — 공급자 엔드포인트가 없으므로 `connect-src` 가 논점이 아니다. 그리고 기존 텍스트 경로를 그대로 쓴다.

**그래서 코호트별로 답이 다를 수 있다.** 이 레포는 이미 프로필별 공급자 기계를 갖고 있다(`model.provider`, `cross_provider`). 아동은 온디바이스, 성인은 유료 — 이 조합이 구조적으로 가능하다.

**반대 방향의 근거도 적는다**: 온디바이스의 비용은 사라지지 않고 **빌드·배포로 옮겨간다**. 모델 바이트를 넣는 일은 이 레포에서 이미 비싼 영역이다(빌드 1~2시간, SDK 바이너리 시딩 선례). 그게 가볍다고 가정하면 안 된다.

## 5. 결정 전에 재야 하는 것

| 재야 할 것 | 누가 | 왜 결정을 막나 |
|---|---|---|
| **네 번째 관문** — 패치된 빌드에서 마이크가 열리나, OS 프롬프트가 뜨나 | Codex (H-01) | 안 열리면 webview 캡처 선택지 전체가 사라지고 워크벤치/네이티브 경로만 남는다 |
| 패치 blast radius — 프리뷰 webview 도 마이크를 요청할 수 있나 | Codex (H-01) | 미성년 제품에서 받아들일 범위인지 판단 |
| 온디바이스 STT 의 **실제** 한국어 지연·정확도 | 측정 필요 | 벤더 CER 로 결정할 수 없다 |
| 모델 바이트 배포 비용 | 측정 필요 | 온디바이스의 진짜 값 |
| Gemini 계열 재조사 | 필요 | 이번 조사 신뢰도가 낮다 |

## 6. 이 문서가 주장하지 않는 것

- **결정이 아니다.** 상태는 제안이고, 고르는 것은 사람이다.
- **어떤 공급자도 이 제품에서 동작한다고 주장하지 않는다.** 오디오를 잡지 못하는 상태에서 전송을 검증할 방법이 없다.
- **가격 비교가 아니다.** 단위가 서로 달라(토큰·분·시간·글자) 같은 축에 놓으려면 예상 사용량 가정이 필요하고, 그 가정이 없다.
- 확인한 것과 확인하지 못한 것을 각 절에 나눠 적었다. **"미검증" 은 "아니다" 가 아니다.**
