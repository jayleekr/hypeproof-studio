# 고등학생 창업 트랙 — 로드맵 재조정 (2026-08-18)

사교육 시장이 **P0** 로 올라왔다. 타겟은 고등학생 창업교육이고, 사이클은
**문제정의 → BM 수립 → 프로덕트 개발 → 재무회계 → IR** 이다.

이 문서는 그 전환의 **결정 기록**이다. 빌드 페이즈 계획은 [METAPLAN.md](../../METAPLAN.md),
제품 철학은 [seven-assets.md](../seven-assets.md) 가 그대로 유효하다 — 여기서 복제하지 않는다.

## 0. 한 줄

> 학생을 **AI-native 창업가**로 만들고, HypeProof Studio 는 **7에셋 경험치를 쌓게 하는 사다리**다.
> 우리가 파는 것은 산출물이 아니라 **과정의 계측된 증거**다.

## 1. 왜 이 방향인가 — 시장 근거

신입 채용이 실제로 무너졌다. 이건 마케팅 수사가 아니라 관측된 수치다.

| 지표 | 값 | 출처 |
|---|---|---|
| 무경력 채용 (2022 피크 → 2026 Q1) | **-73%** | AutoApplyMax |
| 생성형 AI 도입 기업의 신입 채용 감소 | 분기당 최대 **-80%** | Metaintro |
| 신입 SW 개발자 고용 (2024 피크 대비) | **-20%** | Metaintro |
| AI 때문에 신입 채용 **이미 동결**한 기업 | **21%** | Resume.org |
| 2027 까지 신입 직군 **자체를 없앨** 계획 | **47%** | Resume.org |
| 대졸(22–27) 실업률 2026 Q1 | **5.7%** (2025-09 엔 9.7% = 고졸과 동률) | Metaintro |
| 빅테크 4사가 AI 창업팀 흡수에 쓴 금액 (2024-03~2026-01) | **$20B+** (정식 인수 0건) | fastaijobs |
| YC 창업자 평균 연령 | 29 → **26세**, 10년만에 25세 미만이 다수 | thevccorner |

연구자들은 이 현상을 **seniorization** 이라 부른다 — 주니어 공고에 판단력·이해관계자
관리 같은 시니어 역량을 요구하는 것.

### 다만 과장하면 안 되는 지점

Micro M&A / acquihire 는 **시니어 1인당 $1–5M** 로 앵커된다. 리버스 acquihire 의
수혜자는 명시적으로 **창업자와 최상위 연구 인력**이지 팀 전체가 아니다. 고등학생
회사가 그 가격표에 오르는 일은 사실상 없다. 그리고 **YC 공동창업자가 2025-09 에
"고등학교는 창업할 때가 아니다"라고 공개 경고**했다 — 우리가 정반대 메시지를 파는
순간 이게 반박 자료로 날아온다.

> **공개 카피 원칙 (확정)**: 결과를 약속하지 않는다. **역량 증명(seniorization 대응)만**
> 약속하고, Micro M&A 는 상단 결말로만 언급한다.

## 4. 커리큘럼 8주 구조

앞 3단계(문제정의·BM·빌드)는 **계속 바뀐다**는 전제로 나선형, 재무·IR 은 마지막 선형.

```
1–2주   문제정의      고객 접촉 — 사람만 (D9). 인터뷰·설문·관찰
3–5주   BM ⇄ 빌드     나선 2바퀴. V1 → 피드백 → V2 (#559 Diff 가 그대로 증거)
6주     재무          AI 코치 주도, 산출물은 사업계획서 재무 파트
7주     IR 준비       리허설 — AI 심사위원이 증거 없는 주장을 먼저 집는다
8주     데모데이      실무자 심사 (D11)
```

### 아동 트랙과의 관계 — 같은 사다리의 다른 계단

```
초3·4   말한 대로 안 나온다          → Intent clarity        (#574 도트 월드, 완료)
초5·6   가설·검증이 들어온다          → Verification reflex   (설계 예정)
고등     남이 안 쓴다 = 진짜 페인포인트 → 문제정의 → 창업 사이클
```

`#574` 의 ENGINE/CONFIG 분리가 그대로 확장된다 — 초3·4 는 CONFIG 만, 초5·6 은
ENGINE 일부, 고등은 ENGINE 전체 + 실제 배포. **커리큘럼 3종이 아니라 하나의 사다리에
계단 3개.**
