# 강사 첫 수업 준비

재사용 안내: https://chalk.hypeproof-ai.xyz/start

Chalk `/authoring`에서 새 초안 작성 → 단계 편집 → 저장 → 다시 열기 → 버전 확인을 수행한다. `/console`은 연습 세션, `/manage`는 학생 현황·지정 공유 피드백 화면이다. 각 API는 별도로 강사 권한을 검증한다.

강사에게는 본인 코드와 배정된 코호트·프로필 ID가 필요하다. Studio에는 강사 코드가 아닌 학습자 참여 코드를 입력한다. 코드 발급과 세션 시작은 별도 상태이며 코호트·프로필이 일치해야 한다.

현재 지원하지 않는 흐름: 계정 가입·자동 인증 갱신, 초안을 학생 Studio 단계로 자동 전달, 초안 저장만으로 수업 활성화. 강사 안내 페이지는 이 기능들이 완료됐다고 표시하지 않는다.

운영 준비는 #735에서 추적한다. Service 배포는 live-session freeze 후 additive migration 0002 → 0003 → Worker 배포 순서다. 0002 재적용과 저장·동시 편집·불변 버전은 `npm --prefix worker run test:authoring:d1`로 검사한다. 스키마를 삭제하는 롤백은 하지 않는다.

## 홈페이지 제작 첫 실습

수업 ID 예: `website-first-lesson`. 대상: 홈페이지 제작을 처음 해보는 성인. 목표: 가상 가게 페이지 제작 → 영업시간 수정 → 모바일 검수 → 파일 재열기.

완료 기준: 390px·1280px에서 내용과 이동을 확인하고, 수정하지 않은 내용이 보존되며, 앱 재실행 후 결과물을 다시 연다. 연습 결과물을 공개한 것으로 기록하지 않는다.

인증 실패 시 운영자는 정상 발급 API 응답을 확인한다. 401을 만료로 단정하지 않고, 403은 응답 원인과 역할·범위를 확인한다. 인증 문자열은 이슈·기록에 남기지 않는다.
