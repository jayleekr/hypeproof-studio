## 3. 주문 확인 절차

### 3-1. 주문 접수 채널
1. **전화 주문** — 매장 직통 번호로 수신
2. **온라인(SNS·앱)** — 영업 시작 후 1시간 이내 확인

### 3-2. 처리 순서

```
① 주문 내용 확인
   - 품목, 수량, 예산, 수령 일시, 메시지 카드 여부

② 재고·준비 가능 여부 확인
   - 냉장고 재고 확인 → 부족 시 거래처에 당일 오전 발주

③ 주문 장부(또는 주문 앱)에 기록
   - 수령 방법: 방문 수령 / 배달 구분 기재

④ 고객에게 확인 문자 발송
   - 예시: "주문 접수 완료되었습니다. [수령일] [수령시간]에 준비해 두겠습니다."

⑤ 제작 및 포장
   - 수령 시간 최소 30분 전 완성 목표

⑥ 수령·배달 완료 후 장부에 완료 표시
```

### 3-3. 취소·변경 요청 처리
- **제작 전**: 즉시 취소·변경 가능, 장부 수정
- **제작 중·완료 후**: 책임자에게 보고 후 안내
