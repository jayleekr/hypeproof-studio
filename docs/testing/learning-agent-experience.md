## 경쟁 비교 실험 프로토콜

합성 홈페이지 A(정상), B(미리 심은 결함 4종)를 시작 파일 해시로 고정한다.
같은 입력·파일·화면 상태와 동등한 기능 권한을 사용한다. 다른 모델/요금제는 그대로
기록하고 UI 성능과 생성 품질을 혼동하지 않는다. 실험마다 빈 계정 상태와 숙련된 상태도 구분한다.

1. 목표와 맥락 입력: 진료시간 변경 이유, 원본 자료, 완료 기준.
2. 실행 중 개입: 추가 요청 예약, 범위 변경, 중지, 재개.
3. 브라우저 확인: 390px/1280px, 결함 발견, 전후 근거.
4. 복구: 잘못된 변경과 수동 편집이 공존하는 상태에서 복구.
5. 독립 과제: 다른 공지 변경을 수행하고 판단을 설명.

S0 진입/S1 입력/S2 실행/S3 승인/S4 결과 검토/S5 복구/S6 오류 화면을 수집한다.
각 캡처는 관측 순서, 실제 입력, 앱·모델·정책·viewport·파일 버전, 결과와 미실행 이유를 갖는다.
영상/이벤트로 클릭 수·대기 시간을 측정한다. 정지 화면에서 소요시간을 추정하지 않는다.

## 학습 효과와 강사 운영 지표

| 가설 | 측정 | 실패/재설계 신호 |
|---|---|---|
| 학생이 실행을 이해한다 | “지금 누구의 판단을 기다리는가”를 상태별로 설명하는 비율 | 도구 성공을 과제 완수로 오인 |
| 승인 묶음이 판단을 보존한다 | 같은 과제의 불필요한 승인 수와 범위 설명 정확도 | 클릭만 줄고 범위 이해 저하 |
| 검수 카드가 검증을 돕는다 | 심은 오류 발견, 정상 대조군 오탐, 미검증 범위 설명 | AI 설명만 반복하거나 미검사 항목을 통과라 답함 |
| 강사가 더 많은 학생을 지원한다 | 학생당 개입 시간, 도움 대기시간, 무신호 학생 누락 | 평균 개선 중 일부 학생 장기 방치 |
| 수업 후 자립에 도움이 된다 | 다른 과제의 수행·복구·판단 설명과 도움 수준 | 시연 과제만 재현 가능 |

첫 사용성 관찰은 성인 5~8명·강사 1~2명을 제안한다. 문제 발견용이며 통계적 학습 효과
입증 표본으로 쓰지 않는다. 실험 순서 효과를 줄이기 위해 제품 순서를 교차 배정하고
관련 경험을 기록한다. 수업 시간과 기관의 평가 조건이 정해지기 전 합격률 임계값을 지어내지 않는다.

운영 규모 목표: 30명 파일럿 후 100명 합성 부하. p50/p95 응답 시작·작업 완료·도움 대기,
실패율·정책 지연·비용·자원 한도를 기록한다. 숫자는 시험 대상 규모이며 검증된 수용량이 아니다.
성능 SLO는 baseline 관측 후 Service 설정으로 확정하고 App 상수에 미리 고정하지 않는다.

## 이번 실행 기록

- React 현재 소스 빌드 및 네이티브/React/공식 문서 캡처 실행. 상세 환경과 캡처는 [연구 자료](../research/agent-experience-2026-09-08/README.md).
- React 합성 입력을 수정해 재실행한 최종 결과: pageerror 0. 레이아웃 6px overflow 관측은 별도 개선 후보.
- 실제 LLM 호출·학생 수업 완주·인증된 경쟁 제품 비교·학습 효과·부하·Computer Use: NOT RUN.
- 문서 검사/링크 확인 결과는 해당 PR의 Tested에 실제 실행 결과로 남긴다.
- 운영 세션·학생 로그·개인 API 자격을 연구 fixture에 포함하지 않았다.
- 멀티모델 공식 문서/제품 이미지 추가 캡처는 [보충 연구](../research/agent-experience-2026-09-08/multi-model.md)에 기록한다. 모델 변경·병렬 비교의 실제 실행 증거는 아니다.

## 단계별 완료 게이트

P0 행에 대응하는 AE-T01~08/10/11/13/15와 기존 회귀를 실행해 근거를 남긴다.
실제 지원 OS별 설치·참여·채팅·검수·복구가 필요하며 macOS 증거로 Windows PASS를 대신하지 않는다.
모든 권한 우회·교차 학생 데이터·복구 손실은 파일럿 차단 사유다.
P1 승인 묶음·외부 인계·예산·운영 중지·학습 관찰은 각 시나리오를 통과한 뒤 확대한다.
E6는 별도의 go/no-go 결정이며 브라우저 수업 출시를 막는 선행 조건이 아니다.
E7의 고정/제한 선택은 AE-T19~21/25와 기존 모델 정규화 회귀가 선행한다.
자동·인계·비교 확대는 AE-T22~24/26을 실제 허용 조합으로 검증한 뒤 진행한다.
수업 기능에 미지원 모델을 추가하려고 검증된 기존 실행기를 우회하지 않는다.
