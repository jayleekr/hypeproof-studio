## 인수할 사용자 행동

강사가 정한 “제작 파트너”가 첫 화면부터 실제 작업 승인·오류·작업 기록까지 같은 대상으로
이해되어야 한다. 이름은 도구 권한·실행 모델을 바꾸지 않는다. AI 고지는 계속 보여야 한다.
기능 A의 [원본/수정 후 화면](../research/agent-experience-acceptance-2026-09-08/README.md)을
이름 혼재의 전후 비교 기준으로 사용한다.

AI 이름·역할 소개·말투·과거 identity·실제 model/provider를 하나의 문자열로 취급하지 않는다.
모델이 본문에서 스스로 이름을 말하는 것은 승인 UI나 당시 실행 모델의 출처가 아니다.
AI 고지에 “코치”가 일반명사로 남는다면 그 범위를 명시하고, 제품 전면의 “코치 제거” 완료로
표현하지 않는다. 역할·말투 설정과 모델 선택은 이 표시 일관성 단위 밖의 미완료 요구사항이다.
