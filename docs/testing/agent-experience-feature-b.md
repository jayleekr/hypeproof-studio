## 인수할 사용자 행동

강사가 정한 “제작 파트너”가 첫 화면부터 실제 작업 승인·오류·작업 기록까지 같은 대상으로
이해되어야 한다. 이름은 도구 권한·실행 모델을 바꾸지 않는다. AI 고지는 계속 보여야 한다.
기능 A의 [원본/수정 후 화면](../research/agent-experience-acceptance-2026-09-08/README.md)을
이름 혼재의 전후 비교 기준으로 사용한다.

| ID | 실제 검수 | 기대 결과 |
|---|---|---|
| B1 | 이름이 고정된 수업을 연결→첫 화면 확인→시작→같은 수업 계속하기 | 수업 요약, 안내, 계속하기 버튼이 현재 이름을 사용. 강사·학생·AI 역할을 혼동하지 않음 |
| B2 | 합성 작업 폴더에서 파일 생성 요청→실제 승인창 거절→재요청·허용 | 승인창의 주체는 현재 AI 이름. 거절 시 파일 없음, 허용한 경로만 생성. 이름 변경만으로 승인 생략/권한 확대 없음 |
| B3 | 허용된 명령/브라우저/위임의 실제 승인 경로와 미허용 조건 | 활성화된 경로만 검수. 이름·대상·행동이 보이며 미허용 기능을 이름 설정으로 열 수 없음. 실행하지 않은 종류는 NOT RUN |
| B4 | SDK가 없는 별도 앱 조건에서 실제 기능 저하 알림 | 현재 이름으로 어느 기능이 제한됐는지 알림. fallback을 정상 SDK 실행으로 표시하지 않음. 이 fixture는 실제 SDK 성공 근거가 아님 |
| B5 | 관찰 기능이 허용된 합성 수업의 실제 작업 기록 열기 | 요청한 사람, AI, 도구의 역할이 구분됨. 과거 실행의 주체 보존은 별도 AE-08 후속으로 표시 |
| B6 | 기본 이름/받침 있는 이름/한글·HTML 문자/40자, 390·1280px·200%·키보드 | 기본 수업 호환, 안전한 텍스트, 자연스러운 조사, 버튼 접근·읽기 가능. 잘림/혼재는 캡처하고 인수 실패로 남김 |

AI 이름·역할 소개·말투·과거 identity·실제 model/provider를 하나의 문자열로 취급하지 않는다.
모델이 본문에서 스스로 이름을 말하는 것은 승인 UI나 당시 실행 모델의 출처가 아니다.
AI 고지에 “코치”가 일반명사로 남는다면 그 범위를 명시하고, 제품 전면의 “코치 제거” 완료로
표현하지 않는다. 역할·말투 설정과 모델 선택은 이 표시 일관성 단위 밖의 미완료 요구사항이다.
