# Child skill 템플릿

임직원이 Phase 1 Q&A로 답을 다 주면, 다음 세 파일을 `~/.claude/skills/<name>/` 에 생성한다. 자리 표시는 `{{ }}` 로 표기.

---

## File 1: `~/.claude/skills/{{name}}/SKILL.md`

```markdown
---
name: {{name}}
description: {{한 줄 — 임직원 역할 + 검색 목적 + 트리거 단어들. 예: "보아치과 데스크 김OO의 환자 상담 자료 검색. '환자 상담 자료 찾아줘', '임플란트 가격대 알려줘', '상담실에서 보여드릴 자료 검색' 같은 말에 발동. web search로 출처 신뢰 가능한 자료를 추려 환자 눈높이로 정리한다."}}
---

# {{name}}

{{한 문단 — 무엇을, 누구를 위해, 왜.}}

## 의도

{{Phase 1에서 받은 Intent clarity 한 문장}}

## 좋은 결과의 모양

{{Phase 1에서 받은 Taste}}

## 매번 같이 던질 컨텍스트

`reference/context.md` 항상 읽고 그 내용을 검색 프롬프트 앞에 붙인다.

## 검증

`reference/verification.md` 의 체크리스트를 통과해야 결과 전달. 통과 못 한 항목은 임직원에게 보여주고 "이건 직접 확인 필요" 라벨 단다.

## AI 위임 경계

{{Phase 1에서 받은 Delegation judgment 한 줄}}

**AI가 하는 것**: web search, 후보 추리기, 요약, 출처 정리.
**사람이 하는 것**: {{환자 직접 발화 문장 / 의학적 final call / 가격 확정 등 임직원이 답한 것}}.

## 실패 신호

{{Phase 1에서 받은 ownership 실패 신호}}

이게 보이면 Phase 2 메타-스킬로 돌아가 "이 턴 기록해줘" 한다.

## 호출 패턴

이 스킬은 다음 같은 한국어로 발동한다: {{트리거 문구들}}.

## 동작 순서

1. `reference/context.md` 읽기
2. 임직원 요청 + context.md 내용 합쳐 web search 프롬프트 구성
3. `WebSearch` (필요 시 `WebFetch`로 출처 본문 확인)
4. `reference/verification.md` 체크리스트 적용
5. 통과한 결과만 정리, 미통과 항목은 "직접 확인 필요" 표시
6. 임직원에게 결과 전달 + "원장님 컨펌 필요한 부분" 명시
```

## File 3: `~/.claude/skills/{{name}}/reference/verification.md`

```markdown
# 검증 체크리스트

검색 결과 받자마자 다음을 확인. 통과 못 한 항목은 결과에 "⚠ 직접 확인 필요" 라벨 단다.

{{Phase 1 Verification reflex에서 받은 항목들. default 시작점:}}

- [ ] 출처가 두 곳 이상인가
- [ ] 출처 중 하나는 공식 기관/학회인가 (식약처, 대한치과의사협회, 등재 논문)
- [ ] 발행 또는 갱신이 3년 이내인가
- [ ] 한국 컨텍스트인가 (해외 자료면 한국 적용 가능성 별도 표시)
- [ ] {{임직원이 추가한 항목들}}

원장님 컨펌 트리거:
- {{가격 확정 / 의학적 판단 / 시술 비교 등 — 임직원이 답한 케이스}}
```

## 생성 시 주의

- 디렉토리 없으면 `mkdir -p ~/.claude/skills/{{name}}/reference`
- `{{name}}` 은 임직원이 본인 결정한 그대로. 메타-스킬이 임의로 안 바꾼다.
- 생성 직후 임직원에게 파일 경로 보여주고: "Claude Code에서 바로 호출 가능합니다. 트리거: `{{트리거 문구}}`"
