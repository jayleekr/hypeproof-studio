수업 작성

초안을 편집하고 저장한 뒤, 확정할 내용을 불변 버전으로 남깁니다. 버전 저장은 수업 시작이나 리허설 합격을 의미하지 않습니다.

강사 연결 이 화면 메모리에서만 사용합니다. URL이나 수업 파일에는 포함하지 않습니다.
초안 선택

초안을 선택하세요.

수업 내용 학생 Studio의 헤더와 답변 이름에 그대로 표시됩니다(40자 이내, 한 줄). 비우면 코호트 기본 규칙(고정 이름 또는 학생이 직접 짓기)을 따르고, 이름을 넣으면 학생이 지은 이름 대신 이 이름이 고정됩니다. 이름은 도구 권한·모델·AI 고지를 바꾸지 않습니다. 버전을 고정한 뒤의 편집은 새 버전에만 적용됩니다.

코호트가 허용한 모델 안에서 선택합니다. 설정은 새 확정 버전부터 적용됩니다.

한 모델로 고정하면 답변과 보조 요청에 같은 모델을 사용합니다. 모델 변경은 새 버전을 고정하고 학생 조건으로 리허설한 뒤 배정하세요.
처리 수준
먼저 수업 모델 목록을 불러오고 모델 사용 방식을 정하세요. 지원 모델에만 적용되며, 같은 설정이라도 모델마다 속도와 사용량이 다릅니다.

코호트가 이미 가진 기능 중에서 줄이기만 합니다. 여기서 새 권한이 생기지는 않습니다.

고른 기능만 이 수업에서 켜집니다. 나머지는 꺼집니다. 여기서 코호트에 없는 기능이 생기지는 않습니다. 브라우저는 실행 경로와 무관하게 하나로 묶여 있습니다.
