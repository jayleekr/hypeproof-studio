Chalk에서 수업안을 저장하고, Studio에서 직접 실습해 보세요.

수업 작성연습 세션학생 현황·피드백참여 코드 발급

1. 강사 연결 준비

운영자에게 본인 강사 코드와 연습용 코호트·프로필을 받으세요. 강사 코드는 Chalk에서, 학습자 참여 코드는 Studio에서 사용합니다.

아직 계정 가입이나 자동 코드 갱신은 제공하지 않습니다. 다른 수업의 코드나 운영자 비밀번호를 공유받지 마세요.

2. 수업안 작성과 저장

  1. 수업 작성에서 강사 코드, 코호트 ID, 프로필 ID를 입력합니다.
  2. 수업 ID를 정하고 새 초안 작성을 누릅니다. 예: website-first-lesson.
  3. 제목·대상·시간·목표를 적고, 단계 추가로 실습 안내와 완료 기준을 넣습니다.
  4. 초안 저장 후 저장 revision을 확인합니다. 같은 수업 ID로 저장된 초안 열기를 눌러 내용을 확인합니다.
  5. 필요하면 편집 내용 내보내기로 파일을 보관합니다. 확정할 때 버전 이름을 넣고 현재 저장본 버전 고정을 누릅니다.

버전 저장은 수업 개설이나 학생 전달을 뜻하지 않습니다. 작성한 단계가 Studio에 자동 표시되는 연결은 아직 제공하지 않습니다.

3. 홈페이지 수업을 직접 해보기

Studio 설치 파일을 받으세요. Mac은 Apple Silicon, Windows는 x64 사용자 설치 파일을 선택합니다.

강사 콘솔에서 배정된 연습 세션을 열고 발급된 학습자 코드를 Studio 시작 화면에 입력합니다. 수업명·코치를 확인한 뒤 별도 연습 폴더에서 시작하세요. 코드 발급만으로 세션이 열리지는 않습니다.

첫 요청 예시: “가상의 꽃집 홈페이지를 만들어줘. 소개, 영업시간, 위치 안내를 넣고 모바일에서도 읽기 쉽게 만들어줘. 개인정보 입력폼은 만들지 말아줘.”

생성 후 영업시간 한 곳을 수정하고, 다른 문구가 보존됐는지 화면과 파일에서 확인하세요. 390px·1280px에서 살펴보고 앱을 다시 열어 파일이 남는지 확인합니다.

4. 막힌 곳 기록하기

화면 이름, 누른 버튼, 오류 문구, 기대했던 결과를 남기세요. 인증정보는 캡처에서 제외합니다. 401은 인증 확인, 403은 역할·수업 범위 확인이 필요합니다. 저장 충돌(409)이면 편집 내용을 먼저 내보내고 저장본을 다시 열어 비교하세요.

학생이 직접 선택한 내용은 도움 요청·공유에서 지정 강사에게 전달할 수 있습니다. 강사는 학생 현황·피드백에서 확인합니다.

Chalk는 강의 작성·운영 화면이고 Studio는 설치해서 사용하는 실습 앱입니다.
